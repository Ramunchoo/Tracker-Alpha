## 1. Télécharger

Clique sur le bouton bleu ci-dessus : le fichier `Poker-Tracker-Setup-1.2.0.exe` se télécharge directement.

Ton navigateur peut dire que le fichier **« n'est pas couramment téléchargé »** (l'application est
récente et pas encore signée numériquement). C'est normal :

- **Chrome** : dans la liste des téléchargements, clique sur **Conserver**.
- **Edge** : survole le téléchargement, clique sur **⋯** → **Conserver** → **Afficher plus** →
  **Conserver quand même**.

## 2. Installer

1. Ouvre le fichier téléchargé.
2. Si Windows affiche **« Windows a protégé votre ordinateur »** : clique sur
   **Informations complémentaires**, puis sur **Exécuter quand même**.
3. Suis l'installation, puis lance **Poker Tracker** depuis le raccourci du bureau.

## 3. Créer ton compte

Au premier lancement : choisis un **pseudo**, entre ton **email** et un **mot de passe**. Tu reçois
un **code à 6 chiffres** par email (regarde aussi dans les spams) : entre-le, c'est prêt.

## 4. Importer tes mains

Onglet **Import** : dépose tes historiques de mains Betclic (fichiers `.txt` ou `.zip`).

Rien à faire : l'application se met à jour **toute seule**. Quand une nouvelle version est prête,
un bandeau propose de redémarrer ; sinon elle s'installe à la prochaine fermeture.
