# Poker Tracker — version alpha

Tracker de performance pour **Betclic Spin & Rush** : CEV par position, analyse de la chance,
replayer de mains, stats spot par spot.

## ⬇️ Télécharger

👉 **[Télécharger la dernière version](https://github.com/Ramunchoo/Tracker-Alpha/releases/latest)**
puis clique sur le fichier `Poker-Tracker-Setup-x.x.x.exe` dans la liste « Assets ».

## Installer

1. Lance le fichier téléchargé.
2. Windows peut afficher **« Windows a protégé votre ordinateur »** : l'application n'est pas encore
   signée numériquement (c'est payant, ce sera fait pour la version finale). Clique sur
   **Informations complémentaires**, puis **Exécuter quand même**.
3. Suis l'installation, puis lance Poker Tracker depuis le raccourci du bureau.

Configuration : Windows 10 ou 11 (64 bits).

## Mises à jour

Rien à faire : l'application se met à jour **toute seule**. Quand une nouvelle version est prête,
un bandeau propose de redémarrer ; sinon elle s'installe à la prochaine fermeture.

## Tes données

Tes mains restent **sur ton PC** : elles ne sont jamais envoyées en ligne.
